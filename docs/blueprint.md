# **App Name**: StockPilot

## Core Features:

- Add Item: Add a new item to the inventory, including name, description, and initial quantity.
- Update Quantity: Adjust the quantity of an existing item in the inventory.
- View Stock Levels: See the current stock levels for all items, sorted and displayed clearly.
- Search/Filter: Find specific items within the inventory by name or category.

## Style Guidelines:

- Primary color: Deep purple (#673AB7) to convey stability and reliability.
- Background color: Light gray (#F5F5F5) for a clean, data-focused look.
- Accent color: Soft lavender (#D1C4E9) to highlight interactive elements.
- Body and headline font: 'Inter', a sans-serif font, for a modern and readable interface.
- Use clear and minimalist icons to represent item categories and actions.
- Design a clean, tabular layout for easy data viewing and management.
- Use subtle transitions and animations when updating or filtering the inventory to provide visual feedback.
